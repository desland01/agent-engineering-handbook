Give your agent the instructions it needs

Choose the skill that fits your problem rather than loading all four for every task. Each is a Markdown folder with instructions, two reference files and OpenAI-compatible interface metadata. Use it with an agent setup that reads Markdown.

  • MISTAKE → CHECKAgent feedback engineering

    Choose and prove a reusable response to an observed failure.

    4 ideas feed it

    Open the skill →skills/agent-feedback-engineering/
  • SETUP → PREVIEW → CHECKAgent-ready workspaces

    Repair the setup, preview or outcome-check gap that blocks a fresh agent.

    8 ideas feed it

    Open the skill →skills/agent-ready-workspaces/
  • CONTEXT → RIGHT PLACEAgent context calibration

    Diagnose missing project knowledge and select the right place for it.

    4 ideas feed it

    Open the skill →skills/agent-context-calibration/
  • GAP → TOOL → CHECKAgent tool adapters

    Bridge a missing capability and verify the intended agent can use it.

    3 ideas feed it

    Open the skill →skills/agent-tool-adapters/

Open a skill to read its instructions and both reference files. The page links its unchanged SKILL.md and its directory on GitHub.
