Portable skills

Four skills, portable to any agent setup

A skill here is a plain directory any agent that reads Markdown can load: the instructions themselves, two reference files, and OpenAI-compatible interface metadata. Adopt the one that matches the failure you actually have. Loading all four for every task makes each of them worse.

  • FAILURE → CHECKAgent feedback engineering

    Choose and prove a reusable response to an observed failure.

    4 ideas feed it

    Open the skill →skills/agent-feedback-engineering/
  • SETUP → PREVIEW → PROOFAgent-ready workspaces

    Repair the setup, preview or outcome-check gap that blocks a fresh agent.

    8 ideas feed it

    Open the skill →skills/agent-ready-workspaces/
  • MISSING → PLACEDAgent context calibration

    Diagnose missing project knowledge and select the right place for it.

    4 ideas feed it

    Open the skill →skills/agent-context-calibration/
  • GAP → ADAPTER → VERIFIEDAgent tool adapters

    Bridge a missing capability and verify the intended agent can use it.

    3 ideas feed it

    Open the skill →skills/agent-tool-adapters/

Each title opens that skill's own page, which holds its raw SKILL.md exactly as shipped, both reference files and its directory on GitHub.
