Idea 03 of 19 · The nineteen ideas

Infra and DX automation now speeds up every agent, not just you

On this page
  1. What was said
  2. How to apply it
  3. When it is useful
  4. Qualification

What was said

Boris's post argues automations have become more important because infra and developer-experience automation speed you up, and if you run many agents, each agent is sped up too — more automation means more output per unit of time. Theo agrees, noting he used to get pushback for pushing fast provisioning and preview environments.

How to apply it

Treat build/test/provisioning time as a multiplier over agent count. Before scaling the number of parallel agents, profile the slow shared steps (env setup, test suites, CI wait) and fix those first.

When it is useful

When deciding where to invest tooling effort on a team running multiple concurrent agent sessions.

Qualification

The direction of the claim is plausible but the magnitude (more output per unit of time) is asserted, not measured in the video.
