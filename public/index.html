Four portable skills

Standalone directories for any agent setup that reads Markdown instructions: SKILL.md, two reference files and agents/openai.yaml. Each title opens the skill file as shipped here; each directory line opens it on GitHub. Adopt one for the failure you actually have — how to install or fold one into an existing skill.

  • Agent feedback engineering

    Choose and prove a reusable response to an observed failure.

    skills/agent-feedback-engineering/
  • Agent-ready workspaces

    Repair the setup, preview or outcome-check gap that blocks a fresh agent.

    skills/agent-ready-workspaces/
  • Agent context calibration

    Diagnose missing project knowledge and select the right place for it.

    skills/agent-context-calibration/
  • Agent tool adapters

    Bridge a missing capability and verify the intended agent can use it.

What was checked

The local lint demonstration proves that the unwanted import passes without its restriction and is rejected with the restriction while the supported import passes. The Melee verifier's original nine tests and current fifteen tests pass; a separate synthetic comparison reproduces the completeness gap and the repair. These are verifier tests with mocked builds, not a real game build.
