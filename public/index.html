Fix the environment and the agent works

You have corrected the same agent mistake three times this week. You fix it by adding a check, a working preview, or one sentence to the right file. Ten short lessons show you where those fixes live, and each ends with one change you can make today.

You will recognise at least one of these ten problems from your own week. Open its lesson and you leave with one fix you can try today.

  1. Name what keeps going wrong

    Start with the failure you saw this week, in your own words, before you look for a lesson.

  2. Read the one lesson that covers it

    Each lesson takes a few minutes and names the sources behind every claim it makes.

  3. Try one change and check it today

    Every lesson ends with one concrete action you can make and then prove worked.

Ten lessons each end in one change

Read them in order, or jump to the problem that cost you an afternoon this week. Every lesson names the sources it draws on and ends with one action you can try today.

Every check below names what it does not prove

  1. RUNThe lint demo accepts the unwanted import without its rule, rejects it with the rule and accepts the supported import.
  2. RUNThe Melee verifier passed its original nine tests and the current set of fifteen.
  3. RUNA synthetic comparison reproduced the completeness gap: the original verifier accepted incomplete source metrics, while the repaired version rejected them.
  4. LIMITThe verifier tests used mocked builds and establish verifier behavior only. No real game build was run.
  5. NOT RUNThe public applications, upload service and private agent systems were not executed for this research.
  6. UNVERIFIEDSponsor performance claims and universal claims about careers and productivity have not been verified.
