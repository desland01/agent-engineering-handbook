What was checked, and what was not

  1. RUNThe lint demo accepts the unwanted import without its rule, rejects it with the rule and accepts the supported import.
  2. RUNThe Melee verifier passed its original nine tests and the current set of fifteen.
  3. RUNA synthetic comparison reproduced the completeness gap: the original verifier accepted incomplete source metrics, while the repaired version rejected them.
  4. LIMITThe verifier tests used mocked builds and establish verifier behavior only. No real game build was run.
  5. NOT RUNThe public applications, upload service and private agent systems were not executed for this research.
  6. UNVERIFIEDSponsor performance claims and universal claims about careers and productivity have not been verified.
