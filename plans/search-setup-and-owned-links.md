- Consent denied or scripts blocked: reading remains useful; collection is absent by design. Test evidence separates this from a broken allowed-consent path.
- Missing authenticated browser: retain sitemap submission/inspection evidence separately. Manual request receipts remain outstanding, not fabricated.
- Preview/build/link failure: repair the actual candidate and run the same check. No production promotion with failed acceptance. Preserve unrelated GSP campaign and Truline work.
- Indexing quota or Google refusal: record the actual response and remaining URLs. A submitted request is never relabeled indexed. No repeated requests or unsupported Indexing API fallback.
